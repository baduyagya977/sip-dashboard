## 🎯 Overview

A **fully interactive, shareable HTML dashboard** for managing and analyzing SIP Yojana branch data. Download it once and share it with anyone - no server or installation needed!

### ✨ Key Features

✅ **CSV/Excel Upload** - Drag-and-drop CSV or Excel file upload
✅ **Real-time Filtering** - Filter by Month, Province, and District
✅ **Interactive KPI Cards** - 6 key performance indicators with growth metrics
✅ **Dynamic Charts** - Province-wise bar charts, District-wise doughnut charts
✅ **Comprehensive Tables** - Province, District, Branch, and Registry summaries
✅ **Modern Design** - Professional Machhapuchchhre theme with red & blue colors
✅ **Fully Standalone** - No internet required after download (uses local resources)
✅ **Responsive** - Works on desktop, tablet, and mobile devices
✅ **Export Ready** - All data sortable and print-friendly

## 📋 CSV File Format

Your CSV must contain these **11 columns** in this exact order:

| Column | Description | Example |
|--------|-------------|---------|
| Date (BS) | Date in Bikram Sambat | 2082.05.28 |
| Month Name | Nepali month name | Bhadra 2083 |
| Province | Province name | Bagmati Pradesh |
| District | District name | Bhaktapur |
| Branch | Branch name | Kamalbinayak Branch |
| Branch Manager | Manager name | Mr. Sujan Kumar Bista |
| Branch Code | 3-letter code | BKT |
| Telephone | Contact number | +977-1-6620120 6620220 |
| Address | Full address | Kamalbinayak Bhaktapur |
| SIP Registered | Number of registrations | 0 |
| Amount | Investment amount | 10000 |

## 💡 How to Use

### Step 1: Upload Data
1. Click the "📁 Upload CSV/Excel File" button
2. Select your CSV or Excel file
3. Confirm file upload

### Step 2: View Dashboard
- KPI calculations appear automatically
- Charts and tables populate with your data
- Filter options become available

### Step 3: Apply Filters
- Select specific months, provinces, or districts
- Combine filters for detailed analysis

### Step 4: Analyze Data
- Compare province and district performance
- Track branch-wise metrics
- Monitor SIP trends

### Step 5: Print or Share
- Use browser Print function (Ctrl+P)
- Share the HTML file via email
- Export data by copying tables
