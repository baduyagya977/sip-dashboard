# 🚀 Quick Start Guide - SIP Dashboard

## 5-Minute Setup

### 1️⃣ Download
```
Download index.html from the repository
```

### 2️⃣ Open
```
Double-click index.html → Opens in your browser
```

### 3️⃣ Upload Data
```
Click "📁 Upload CSV/Excel File" button
Select your CSV file with these columns:
- Date (BS)
- Month Name
- Province
- District
- Branch
- Branch Manager
- Branch Code
- Telephone
- Address
- SIP Registered
- Amount
```

### 4️⃣ Analyze
```
✓ KPIs appear automatically
✓ Charts populate with data
✓ Use filters to drill down
```

### 5️⃣ Share
```
Email the index.html file to anyone
They open it & can upload their own data
```

### Section 3: District Analysis

### Section 4: Branch Details

- Individual branch metrics

### Section 5: Registry
- Full transaction history
- All branch records

## 🎯 How to Filter

1. **By Month**: Select from "Month Filter" dropdown
2. **By Province**: Select from "Province Filter" dropdown
3. **By District**: Select from "District Filter" dropdown
4. **Combine**: Apply multiple filters together
5. **Reset**: Click "Reset Filters" to clear all

## ❓ Common Questions

**Q: Do I need internet?**
A: Only to download. After that, works completely offline.

**Q: Can I share it with others?**
A: Yes! Email the index.html file. They just open it and upload their data.

**Q: My data didn't load. What's wrong?**
A: Check column headers match exactly:
- Date (BS)
- Month Name
- Province
- District
- Branch
- Branch Manager
- Branch Code
- Telephone
- Address
- SIP Registered
- Amount

**Q: Can I modify the design?**
A: Yes! Edit the CSS section in index.html

**Q: Is my data saved?**
A: No, all processing happens in your browser locally. No data is sent anywhere.
